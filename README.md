# 📋 JSON Formatter & Validator

Lekkie, szybkie i działające w 100% po stronie przeglądarki narzędzie do formatowania, upiększania oraz sprawdzania poprawności (walidacji) kodu JSON.

🌐 **Wypróbuj online:** [https://ver3k12.github.io/json-formatter/](https://ver3k12.github.io/json-formatter/)

---

### ✨ Funkcje
* **Upiększanie (Pretty Print):** Automatycznie dodaje wcięcia i czytelną strukturę do zbitego kodu JSON.
* **Walidacja w czasie rzeczywistym:** Wykrywa błędy składniowe (np. brakujące przecinki lub cudzysłowy) i wskazuje je użytkownikowi.
* **Szybkie kopiowanie:** Pozwala jednym kliknięciem skopiować sformatowany wynik do schowka.
* **Czysty kod:** Napisane w czystym HTML, CSS oraz JavaScript (Vanilla JS) bez zbędnych bibliotek.

---

### 🛠️ Technologie
* HTML5
* CSS3 (Styl inspirowany ciemnym motywem GitHub)
* JavaScript (ES6+)
